## 当前结论与未解决点

固定24格条件合成面板、两种方法、三个修正目标，共144条两笔序列。主目标 U=.001、单步参数欧氏距离上限1下，新机制两笔都匹配0/24格，完整端口距离对照5/24格，尚不能形成主目标的匹配保持比较。小目标 U=.0001 下双方共同匹配20格，新机制串扰7格较低、13格较高，没有系统改善。

六个固定基点上，两方法同关联梯度方向几乎一致，新机制的梯度范数约为对照的一半；暖历史的跨关联梯度仍近共线。当前需要解决的是关联信用方向的区分，而不是仅降低学习率或教师强度。这是局部诊断，不是全局等价定理，也不是真实视觉结果。

研究背景不变：陌生静态室内导航中的在线跨视角地点关联。模拟、训练和真实视觉验证继续暂缓；无隐藏位姿、深度、地点标签或奖励进入学习。本次同步未运行新实验。
